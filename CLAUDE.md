# DistroNexus — Claude Code Instructions

## Language

**All project documentation must be written in English.** This applies to:
- Specs and requirements (`docs/specs/`)
- Architecture documents (`docs/architecture/`)
- Development guides (`docs/development/`)
- Release notes (`docs/release_notes/`)
- Inline code comments
- Commit messages and PR descriptions

Conversation with the user may be in any language the user prefers. Only the written artefacts committed to the repository must be in English.
