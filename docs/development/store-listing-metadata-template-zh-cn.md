## 应用描述（长描述，≤ 10,000 字符）
DistroNexus 是一款用于管理 Windows Subsystem for Linux（WSL）的 Windows 桌面应用。  
它帮助开发者发现发行版、安装实例，并为常见开发场景应用可复用的环境模板。

核心能力：
- 在统一桌面界面中发现并管理 WSL 发行版。
- 应用内置模板快速搭建语言/运行时与开发工作流环境。
- 执行本地 WSL 配置流程，并提供透明的进度与日志反馈。
- 初次配置后可进行离线本地管理。

重要前置条件：
- Windows 10/11，且已启用 WSL 功能。
- 某些操作可能需要管理员权限。

## 隐私政策文本（可直接复制）
生效日期：2026-02-16

DistroNexus 是一款本地优先的 Windows 应用，用于管理 Windows Subsystem for Linux（WSL）发行版并应用开发模板。大多数操作均在用户设备本地执行。

我们处理的数据：
- 存储在 `AppData\\Roaming\\DistroNexus` 下的本地应用设置与偏好。
- 用于目录/模板加载与离线可用性的本地缓存文件。
- 执行 WSL 管理命令所需的用户触发操作数据。
- 本地命令输出与日志。

用途：
- 提供用户请求的 WSL 管理与模板自动化功能。
- 保存用户偏好并提升本地使用体验。
- 展示执行进度与诊断信息。

网络与共享：
- 应用可能访问已配置网络端点以下载目录/模板内容。
- 核心本地流程不要求账户登录。
- 不包含应用内购买。
- DistroNexus 不会主动出售个人数据。

保留与删除：
- 本地设置/缓存/日志会保留在设备上，直到用户删除。
- 用户可手动删除本地数据或通过卸载应用移除。

隐私联系邮箱：lazyworkshop.deron@gmail.com

- 不包含应用内购买。
- 核心验证场景：
  1. 启动应用并加载 catalog/templates。

  3. 验证离线启动与本地模板驱动流程。

### 受限能力说明（runFullTrust，可直接复制）
DistroNexus 需要 `runFullTrust` 能力，是因为它作为桌面 WSL 管理工具，必须调用本地 Windows/WSL 命令组件（包括 `wsl.exe`）来执行用户主动发起的操作，例如列出发行版、创建/导入/删除实例、应用环境模板等。这些功能仅依赖受限容器权限无法完成。该能力仅用于用户显式触发的本地管理流程，不用于后台监控、提权或隐藏远程控制。应用不包含内购。用户数据（设置/缓存/日志）默认保存在本地，网络访问仅用于已配置的目录/模板来源。
