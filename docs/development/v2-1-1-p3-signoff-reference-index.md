## Owner Mapping
- Engineering sign-off owner: Engineering Lead
- QA sign-off owner: QA Lead
- Release sign-off owner: Release Manager

## Escalation Path
1. Record unresolved/deferred item in acceptance checklist exception handling section.
2. Attach owner, milestone, and follow-up reference.
3. Initiate sign-off handoff using template and request explicit decision.
4. Escalate unresolved blockers to release manager for go/no-go decision.
