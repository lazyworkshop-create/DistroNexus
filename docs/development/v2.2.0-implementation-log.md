## F-01 — VHDX Disk Compaction

_Status: **Complete**_

### Key Decisions

- VHDX path resolved from registry `HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss\{guid}\BasePath`
- `fstrim -av` executed inside instance before compaction to zero deleted blocks; non-fatal if fstrim not present
- Prefer `Optimize-VHD -Mode Full` (Hyper-V module); fall back to `diskpart compact vdisk` when unavailable
- `diskpart` requires administrator elevation — detected via `Test-AdminPrivilege` helper (WindowsPrincipal.IsInRole)
- Auto-stop running instance before compact, auto-restart after if it was running
- `CompactInstanceAsync` in `WslManagerService` delegates to `Compress-DistroNexusInstance` cmdlet with `VeryLongOperationTimeoutSeconds` (300s)
- Helper functions `Get-InstanceVhdxPath` and `Test-AdminPrivilege` live in the same cmdlet file (module-private)

## E-04 — Instance Backup Scheduling

_Status: **Complete**_

### Key Decisions

- Four cmdlets: `New-`, `Remove-`, `Get-DistroNexusBackupSchedule` + `Invoke-DistroNexusBackup`
- All four cmdlets live in separate files under `src/PowerShell/Public/`
- Schedule persistence: `%APPDATA%\DistroNexus\backup-schedules.json` (JSON array)
- Private I/O helpers (`Get-BackupScheduleEntries`, `Save-BackupScheduleEntry`, `Save-AllBackupScheduleEntries`) live in `New-DistroNexusBackupSchedule.ps1` — loaded once via psm1 glob
- Task Scheduler integration: `Register-ScheduledTask` / `Unregister-ScheduledTask`; task action is `pwsh -NonInteractive -File backup-runner.ps1`
- `backup-runner.ps1` placed in module root (`src/PowerShell/`); invoked by the Task Scheduler task
- Frequency format: `"Daily"` | `"Weekly:Monday"` | `"Monthly:1"` — parsed with `-Regex` switch
- `Invoke-DistroNexusBackup` handles the full lifecycle: stop → export → restart → retention enforcement
- Retention: sorted by `LastWriteTime` descending; oldest files beyond `RetentionCount` are deleted
- Backup filename pattern: `<Name>-backup-<yyyyMMdd-HHmmss>.tar`
- `IBackupService` / `BackupService` added to C# layer; `BackupService` accepts optional `appDataDir` ctor arg for testability
- `BackupService.InvokeBackupAsync` delegates to `Invoke-DistroNexusBackup` via `ExecuteModuleCmdletAsync` (VeryLong timeout = 300s)
- `BackupSchedule` model in `Models/` with `TaskName` computed property
- Registered as Singleton in `App.xaml.cs`

## E-07 — Proactive Cache Invalidation

_Status: **Complete**_

### Key Decisions

- `Invalidate-InstanceCache` private function added to `Cache.ps1`; sets module-scoped `$script:__CacheState.IsStale = $true`
- `Reset-CacheInvalidationState` private function resets the flag after a successful refresh
- `Get-CacheInvalidationState` private function returns the shared state object
- `Get-DistroNexusCache` public cmdlet exposes cache diagnostics: CacheAge, EntryCount, IsStale, LastReason
- C# `WslEventWatcher` uses a `System.Threading.Timer` for the debounce window (default 2s); avoids WMI in Store-restricted environment
- `WslEventWatcher` exposes `SimulateProcessEvent(string processName)` for testability and for `WslManagerService` to signal after mutating operations

- `IWslEventWatcher` interface includes `Start()`, `Stop()`, `SimulateProcessEvent()`, and `CacheInvalidationRequested` event
- Registered as Singleton in `App.xaml.cs`; 10-minute TTL fallback kept in `Get-DistroNexusInstance`

## E-08 — Decouple PowerShell Service Layer

_Status: **Complete**_

### Key Decisions

- New abstraction `IWslCliRunner` / `WslCliRunner` wraps `System.Diagnostics.Process` for wsl.exe calls; Unicode output encoding set explicitly
- `WslCliResult` model captures ExitCode, Output, Error; `Success` is a computed property
- `WslCliRunner` exposes two static parse helpers: `ParseWslListVerbose(string?)` and `ParseWslListRunning(string?)` — both are pure functions, easy to unit test without a real process
- `WslInstanceDescriptor` internal record carries parsed Name, State, Version, IsDefault from `--list --verbose` output
- `WslManagerService` gains an optional `IWslCliRunner? wslCliRunner = null` constructor parameter (backward-compatible)
- When `_wslCliRunner` is non-null, `GetInstancesAsync` delegates to `GetInstancesNativeAsync` (Phase 1, E-08-1); otherwise falls back to existing PS path
- `GetInstancesNativeAsync` calls `wsl --list --verbose --all`, parses with `WslCliRunner.ParseWslListVerbose`, and maps to `WslInstance`
- No change to public PS cmdlet API; PS module continues to function as a standalone tool
- `IWslCliRunner` implements `IDisposable` (Process is disposed per invocation)
- Registered as Singleton in `App.xaml.cs`; `WslManagerService` receives it via DI

## E-09 — Unified Error Code System

_Status: **Complete**_

### Key Decisions

- `DistroNexusErrorCode` enum in `DistroNexus.Core.Exceptions` defines all codes with stable numeric prefixes:
  1xxx (instance lifecycle), 2xxx (disk/VHDX), 3xxx (Docker), 4xxx (backup/export), 5xxx (config), 9xxx (system)
- `WslException` gains a `DistroNexusErrorCode Code` property; new constructors accept a `DistroNexusErrorCode` as the second argument; all legacy int-errorCode constructors preserved (default `Code = UnknownError`)
- `WslOperationException` gains `Code` property; constructor signatures updated with `DistroNexusErrorCode code` as second positional parameter to avoid breaking callers
- Concrete subclasses pass their canonical code in every constructor:
  - `WslInstanceNotFoundException` → `InstanceNotFound (1001)`
  - `WslInstanceAlreadyExistsException` → `InstanceAlreadyExists (1004)`
  - `WslExportFailedException` → `ExportFailed (4001)`
  - `WslImportFailedException` → `ImportFailed (4002)`
  - `WslOperationCanceledException`, `WslOperationTimeoutException` → `UnknownError (9999)` (generic lifecycle events)
- Error code reference documented in `docs/development/error-codes.md`
