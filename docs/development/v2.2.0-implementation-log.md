## F-01 — VHDX Disk Compaction

_Status: **Complete**_

### Key Decisions

- VHDX path resolved from registry `HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss\{guid}\BasePath`
- `fstrim -av` executed inside instance before compaction to zero deleted blocks; non-fatal if fstrim not present
- Prefer `Optimize-VHD -Mode Full` (Hyper-V module); fall back to `diskpart compact vdisk` when unavailable
- `diskpart` requires administrator elevation — detected via `Test-AdminPrivilege` helper (WindowsPrincipal.IsInRole)
- Auto-stop running instance before compact, auto-restart after if it was running
- `CompactInstanceAsync` in `WslManagerService` delegates to `Compress-DistroNexusInstance` cmdlet with `VeryLongOperationTimeoutSeconds` (300s)
- Helper functions `Get-InstanceVhdxPath` and `Test-AdminPrivilege` live in the same cmdlet file (module-private)

## F-02 — Docker Desktop Integration

_Status: **Complete**_

### Key Decisions

- Docker settings path: `$env:APPDATA\Docker\settings-store.json` (4.30+) with fallback to `settings.json`
- Docker installation detected via `$env:LOCALAPPDATA\Docker\Docker Desktop.exe`; registry fallback
- `integratedWslDistros` JSON array read/written atomically (full JSON rewrite)
- WSL v1 instances rejected in `Enable-DistroNexusDockerIntegration` with descriptive error
- Reserved distros `docker-desktop` and `docker-desktop-data` always return `Unavailable`
- `DockerIntegrationStatus` enum lives in `Services/` (not `Models/`) alongside the service
- `DockerIntegrationService.IsDockerDesktopInstalledAsync` is `virtual` to support test subclassing
