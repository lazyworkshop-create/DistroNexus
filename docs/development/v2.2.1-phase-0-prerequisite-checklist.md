**Why**: `WslInstanceViewModel` is currently a nested `partial class` inside `MainViewModel.cs` (starting at ~line 573, 400+ lines). Adding `IsSelected`, `Tags`, `DockerIntegrationEnabled`, `OpenDetailsCommand`, and other new members will make the file unmanageable.

- [ ] Move the entire `WslInstanceViewModel` class from `MainViewModel.cs` to the new file
- [ ] Keep the same namespace and `partial class` declaration if needed
- [ ] Ensure all existing references compile (`MainViewModel.Instances`, event handlers, etc.)

### P0-2: Fix service-locator anti-pattern in `MainViewModel`

**Why**: `LoadInstancesAsync` currently resolves services per-loop via `_serviceProvider.GetRequiredService<ITagService>()`. This is a service-locator anti-pattern that worsens with new dependencies (Design Review #14).

- [ ] Add `ITagService` as a constructor parameter on `MainViewModel`
- [ ] Add `IBackupService` as a constructor parameter on `MainViewModel`
- [ ] Add `IDockerIntegrationService` as a constructor parameter on `MainViewModel`
- [ ] Remove `_serviceProvider.GetRequiredService<T>()` calls in `LoadInstancesAsync` for these services
- [ ] Update DI registration in `App.xaml.cs` if needed
- [ ] Verify all service injection resolves correctly at startup

**Acceptance**:
- [ ] No `GetRequiredService` calls for `ITagService`, `IBackupService`, or `IDockerIntegrationService` in `MainViewModel`
- [ ] App starts and loads instance list correctly

---

### P0-3: Introduce minimal `IDialogService` interface

**Why**: New tab ViewModels (`DiskTabViewModel`, `IntegrationsTabViewModel`, etc.) need to show error/confirmation dialogs but don't inherit from any base that provides `ShowAlert`. A minimal dialog service interface enables testability and avoids code duplication (Design Review #11).

- [ ] Create `src/Client/DistroNexus.Core/Interfaces/IDialogService.cs`:
  ```csharp
  public interface IDialogService
  {
      Task ShowAlertAsync(string title, string message);
      Task<bool> ShowConfirmAsync(string title, string message);
  }
  ```
- [ ] Create `src/Client/DistroNexus.Desktop/Services/DialogService.cs` implementing `IDialogService` using existing `ContentDialog` / `MessageBox` pattern from `MainViewModel`
- [ ] Register `IDialogService` → `DialogService` in `App.xaml.cs` DI container (singleton)
- [ ] Do NOT refactor existing ViewModels to use it yet (that's optional cleanup)

**Acceptance**:
- [ ] `IDialogService` exists with `ShowAlertAsync` and `ShowConfirmAsync`
- [ ] `DialogService` implementation compiles and is registered in DI
- [ ] Existing functionality unaffected

**Why**: Design Review #3 — the WSL Config editor (Phase 3) needs to call `wsl --shutdown`. `IWslManagerService` has no such method.

- [ ] **Option A (recommended)**: Add `Task ShutdownWslAsync(CancellationToken ct = default)` to `IWslManagerService`
- [ ] Implement in `WslManagerService` via `IWslCliRunner.RunAsync("--shutdown", ct)`
- [ ] Add unit test with mocked `IWslCliRunner`

- [ ] **Option B**: Document that `WslConfigSectionViewModel` calls `IWslCliRunner.RunAsync("--shutdown")` directly (simpler but less testable from ViewModel layer)

**Acceptance**:

- [ ] Unit test with mock passes
