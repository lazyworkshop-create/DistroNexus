# v2.2.1 Phase 4 — Integrations & Diagnostics (Group C)

**Phase**: 4 of 7  
**Status**: Not Started  
**Dependencies**: Phase 1 (Integrations and Network tabs must exist in InstanceDetailDialog)  
**Can parallel with**: Phase 3, 5, 6  
**Requirements**: C-01 (Docker), C-02 (Network/Ports)  
**Design References**: [Design §2.5.3, §2.5.4](../specs/v2.2.1-design.md)

---

## Goal

Fill the Integrations and Network tabs of `InstanceDetailDialog` with functional content. Add Docker status indicator to instance cards.

---

## Tasks

### P4-1: Implement Integrations Tab — Docker Desktop

**Req**: C-01-1 through C-01-8

#### P4-1a: Integrations Tab UI (`IntegrationsTabView.xaml`)

- [ ] Docker Desktop Integration section:
  - Status display: "Enabled" / "Disabled" / "Unavailable" (C-01-1)
  - Loading spinner during `GetIntegrationStatusAsync` call (C-01-2)
  - Toggle switch to enable/disable Docker integration (C-01-3)
  - When Docker not installed: disable toggle, show "Install Docker Desktop" link to official download page (C-01-4)
  - Success banner: "Restart Docker Desktop for the change to take effect" + Dismiss button (C-01-5)
  - WSL v1 guard: disable toggle, show "Docker requires WSL v2" (C-01-6, UX-06)
- [ ] Tab hidden entirely for `docker-desktop` and `docker-desktop-data` instances (C-01-7)
- [ ] Use `{DynamicResource}` for all brushes

#### P4-1b: Integrations Tab ViewModel (`IntegrationsTabViewModel.cs`)

- [ ] `InitializeAsync()`:
  - Call `IsDockerDesktopInstalledAsync()` → set `IsDockerInstalled`
  - If installed: call `GetIntegrationStatusAsync(instanceName)` → set status
  - Handle `IsWslV1` check
- [ ] `ToggleDockerCommand`:
  - Call `SetIntegrationAsync(instanceName, enabled, ct)`
  - On success: update status, show restart banner (C-01-5)
  - On failure: `FormatAlertMessage(ex)` via `IDialogService`
- [ ] `DismissRestartBannerCommand`: hide banner
- [ ] `IsTabVisible`: return `false` for `docker-desktop` / `docker-desktop-data` instances (C-01-7)

**Acceptance** (C-01):
- [ ] `docker version` works inside WSL after enabling integration
- [ ] Integration stops working after disabling
- [ ] UI greys out toggle and shows install link when Docker Desktop not installed

### P4-2: Add Docker Status Indicator to Instance Cards

**Req**: C-01-8

- [ ] Add `DockerIntegrationEnabled` observable property (nullable bool) to `WslInstanceViewModel`
- [ ] On dashboard load (`LoadInstancesAsync`), call `GetIntegrationStatusAsync` asynchronously for each instance
  - Set `DockerIntegrationEnabled = true/false/null`
  - Skip for WSL v1 instances and `docker-desktop`/`docker-desktop-data`
- [ ] In `MainWindow.xaml` instance card template:
  - Add small Docker whale icon + coloured dot indicator:
    - Green dot = enabled
    - Grey dot = disabled or unavailable
    - Hidden if `DockerIntegrationEnabled == null`
  - Position: after the state badge

**Acceptance**:
- [ ] Docker icon visible on instance cards with Docker integration queried
- [ ] Green dot for enabled, grey dot for disabled
- [ ] No icon for WSL v1 or Docker system instances

### P4-3: Implement Network Tab — Port Forwarding Visualization

**Req**: C-02-1 through C-02-6

#### P4-3a: Network Tab UI (`NetworkTabView.xaml`)

- [ ] Instance IP display at top of tab (C-02-2)
- [ ] `DataGrid` with columns (C-02-3):
  - Protocol
  - Local Address
  - Port
  - Process
  - Windows Proxy (bold/accent when `netsh portproxy` rule exists) (C-02-4)
- [ ] Each row: **Copy** button that copies `<address>:<port>` to clipboard (C-02-5)
- [ ] **Refresh** button to re-query IP + ports (C-02-6)
- [ ] Stopped instance guard: show "Start the instance to view network information" placeholder (C-02-1, UX-08)
- [ ] Use `{DynamicResource}` for all brushes

#### P4-3b: Network Tab ViewModel (`NetworkTabViewModel.cs`)

- [ ] `InitializeAsync()`:
  - Check if instance is running; if not, show placeholder (C-02-1)
  - If running:
    - Call `GetInstanceIpAddressAsync(instanceName)` → display IP (C-02-2)
    - Call `GetPortMappingsAsync(instanceName)` → populate DataGrid (C-02-3)
- [ ] Port mapping model for UI:
  - Protocol, LocalAddress, Port, Process, HasWindowsProxy (C-02-4)
- [ ] `CopyAddressCommand(row)`: copy `{address}:{port}` to clipboard (C-02-5)
- [ ] `RefreshNetworkCommand`: re-query both IP and ports (C-02-6)
- [ ] Error handling for `ss` utility not installed or other failures

**Acceptance** (C-02):
- [ ] Ports shown match `ss -tlnp` output inside WSL terminal
- [ ] A port with a `netsh portproxy` rule is visually distinguished
- [ ] Network tab shows placeholder when instance is stopped
- [ ] WSL IP address matches `hostname -I` inside the instance
