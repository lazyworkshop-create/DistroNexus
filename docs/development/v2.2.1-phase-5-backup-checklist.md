## Goal

Fill the Backup tab of `InstanceDetailDialog` with schedule editor, Backup Now, and history list. Integrate backup cleanup into instance removal flow.

### P5-2: Implement Backup Tab ViewModel

**Req**: D-01-1 through D-01-5, Design Review #5

- [ ] Implement `BackupTabViewModel.cs`:
  - Constructor receives: `WslInstanceViewModel`, `IBackupService`, `IDialogService`
  - `InitializeAsync()`:
    - Call `GetSchedulesAsync()` → find schedule for current instance
    - If schedule exists: populate form fields (parse Frequency encoding)
    - If no schedule: show empty form with defaults
    - Load backup history (see P5-3)
  - Observable properties:
    - `FrequencyType` (Daily/Weekly/Monthly)
    - `SelectedDayOfWeek` (for Weekly)
    - `SelectedDayOfMonth` (for Monthly)
    - `BackupTime` (TimeSpan or DateTime)
    - `DestinationPath` (string)
    - `RetentionCount` (int, 1–30)
    - `HasSchedule` (bool — drives Remove button visibility)
    - `IsBackingUp` (bool — progress indicator)
  - `SaveScheduleCommand`:
    - Validate all fields
    - Construct `BackupSchedule` with encoded `Frequency`
    - Call `SaveScheduleAsync(schedule)`
    - Show success feedback
  - `RemoveScheduleCommand`:
    - Show `ConfirmDialog` (UX-03)
    - Call `RemoveScheduleAsync(instanceName)`
    - Clear form
  - `BackupNowCommand`:
    - Set `IsBackingUp = true`
    - Call `InvokeBackupAsync(instanceName, destination, retention, ct)`
    - Show progress (indeterminate)
    - On success: refresh backup history
    - On failure: `FormatAlertMessage(ex)`
    - Set `IsBackingUp = false`

### P5-3: Implement Backup History List

**Req**: D-01-5, Design Review #5

`IBackupService` has no history query method. History is derived from the filesystem.

- [ ] In `BackupTabViewModel.LoadBackupHistoryAsync()`:
  - Scan `DestinationPath` for `*.tar` and `*.tar.gz` files matching instance name pattern
  - Sort descending by `CreationTime`
  - Cap at 10 entries (or schedule's `RetentionCount`)
  - Map each file to `BackupHistoryEntry`:
    - `Timestamp` = file creation time
    - `FileSizeBytes` = file length
    - `FilePath` = full path
    - `Status` = Success (inferred; no failure detection without sidecar log)
- [ ] Create `BackupHistoryEntry` model in `DistroNexus.Core/Models/`:
  ```csharp
  public class BackupHistoryEntry
  {
      public DateTimeOffset Timestamp { get; set; }
      public long FileSizeBytes { get; set; }
      public string FilePath { get; set; } = string.Empty;
      public bool IsSuccess { get; set; } = true;
  }
  ```
- [ ] Display history in the Backup tab UI
- [ ] Auto-refresh history after Backup Now completes
