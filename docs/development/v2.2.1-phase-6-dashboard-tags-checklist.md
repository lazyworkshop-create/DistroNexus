  - `AddTagCommand(tagText)`:

### P6-4: Implement Tag Filter Bar

**Req**: E-02-5, Design Review #4

#### P6-4a: Create `TagFilterBar.xaml`

- [ ] Create `src/Client/DistroNexus.Desktop/Controls/TagFilterBar.xaml` + `.xaml.cs`
- [ ] Positioned between toolbar row and instance list in `MainWindow.xaml`
- [ ] Shows all tags in use as selectable pills (populated from `GetAllTagsAsync`)
- [ ] Selected tags shown with visual distinction (accent colour, ×)
- [ ] **Clear All** button
- [ ] **Group by Tag** toggle button (E-02-6)
- [ ] Collapses to zero height when no tags exist for any instance

#### P6-4b: ViewModel Support

- [ ] Add to `MainViewModel`:
  - `AvailableTags: ObservableCollection<TagFilterViewModel>` — all tags with `IsSelected` state
  - Create `TagFilterViewModel`:
    ```csharp
    public class TagFilterViewModel : ObservableObject
    {
        public string Name { get; set; }
        public bool IsSelected { get; set; }  // observable
    }
    ```
  - `TagFilterChangedCommand`: triggered when any tag selection changes
  - `ClearTagFiltersCommand`: deselect all tags
  - `IsGroupByTag: bool` observable property
  - `ToggleGroupByTagCommand` (E-02-6)

#### P6-4c: ICollectionView Integration (Design Review #4)

- [ ] Add `ICollectionView InstancesView` property to `MainViewModel`:
  ```csharp
  public ICollectionView InstancesView { get; }
  // In constructor:
  InstancesView = CollectionViewSource.GetDefaultView(Instances);
  ```
- [ ] Update `MainWindow.xaml` — bind `ItemsSource` to `InstancesView` instead of `Instances`
- [ ] Implement filter predicate:
  ```csharp
  _instancesView.Filter = activeFilters.Any()
      ? o => activeFilters.All(f => ((WslInstanceViewModel)o).Tags.Contains(f.Name))
      : null;
  ```
- [ ] Implement Group by Tag:
  - When active: add `PropertyGroupDescription` to `GroupDescriptions`
  - Note: multi-tag grouping is complex (one instance can have multiple tags)
  - For v2.2.1: use primary tag (first tag) for grouping, with clear documentation that multi-tag grouping is deferred
  - When inactive: clear `GroupDescriptions`
- [ ] Refresh AvailableTags when instances are loaded or tags change

**Acceptance** (E-02):
- [ ] Tags survive application restart
- [ ] Filtering by tag shows only matching instances
- [ ] Group by Tag reorganizes the list into tag-labelled sections
- [ ] Clear All removes all tag filters
- [ ] Filter bar hides when no tags exist
