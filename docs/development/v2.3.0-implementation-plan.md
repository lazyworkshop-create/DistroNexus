## Slice S01: Safe execution, persistence, validation, and diagnostics foundation

### Status

Committed

### Objective

Provide structured, bounded process execution and crash-safe versioned local persistence shared by all later capabilities.

### Sources

Design sections 5.1, 5.2, 6.1, 7, 8, 11.1, and 12.1; UX-07, UX-08, and backward-compatibility requirements. Accepted implementation commit: `573e505a`.

### Dependencies

None.

### Allowed Paths

`src/Client/DistroNexus.Core/{Exceptions,Interfaces,Models,Services}/**`, `src/Client/DistroNexus.Tests/{Exceptions,Models,Services}/**`, and this plan.

### Excluded Paths

Desktop UI, PowerShell, release/signing/store workflows, WSL runtime mutation, and unrelated existing services except compatibility migration to the new runner/store.

### Contract and Documentation

Define typed process results, error ranges, redaction/validation contracts, versioned store envelopes, revision conflicts, and compatibility adapters without renumbering existing errors.

### Implementation Scope

Implement `IProcessRunner` using `ArgumentList`, timeout/cancellation/output bounds and metadata; atomic optimistic JSON storage with schema/revision and recovery; centralized redaction and validation primitives. Preserve existing public interfaces through adapters.

### Test Scope

Argument capture, timeout, cancellation, output bounds, malformed encoding, redaction, atomic failure, conflict, migration, newer schema, and compatibility regression tests.

### Acceptance Criteria

- No new untrusted field is executed through a constructed argument string or implicit shell.
- Failed or conflicting writes retain the prior valid document and return structured errors.
- Existing error numbers and supported settings/backup reads remain compatible.

### Verification Commands

`dotnet test src/Client/DistroNexus.Tests/DistroNexus.Tests.csproj -c Debug --filter "FullyQualifiedName~ProcessRunner|FullyQualifiedName~VersionedStore|FullyQualifiedName~Redaction|FullyQualifiedName~ErrorCode|FullyQualifiedName~SettingsService|FullyQualifiedName~BackupService"`; `dotnet build src/Client/DistroNexus.slnx -c Debug`.

### Commit Boundary

One cohesive foundation change containing contracts, implementations, compatibility migrations, and tests.

### Out of Scope

Feature-specific probes, UI, elevated execution, runtime acceptance, and release publication.
