# Gemini Hero Image Prompts (Windows Store Launch Success)

## Usage Notes
- Recommended size: `1080x1920` (WeChat vertical cover) or `900x383` (WeChat horizontal sub-cover).
- Recommended style: modern, technical, professional, restrained lighting.
- Global constraints: no real brand logos (Microsoft/Windows), no recognizable faces, no readable text in image output.

## Prompt A (Launch Milestone Style)
**Prompt:**
> Create a premium hero poster for a technical article about a successful Windows app store launch.
> Visual style: modern, trustworthy, high-end technology aesthetic.
> Main elements: a desktop app UI card, a launch-success badge, and abstract code/process line graphics in the background.
> Composition: centered focus, with clean empty space at top and center for later Chinese headline overlay.
> Color palette: deep blue and cyan gradient with subtle orange accents.
> Output constraints: no readable text, no watermarks, no logos, high resolution, crisp edges, low noise.
> Keywords: software launch, app store release, desktop app, engineering milestone, clean UI, premium cover art.

## Prompt B (Engineering Postmortem Style)
**Prompt:**
> Create a technical postmortem-style cover image for an article about going from zero to a successful Windows Store launch.
> Main visual: an abstract timeline flow represented by icons/shapes only (prepare -> package -> submit -> review -> launch), with no text.
> Background details: subtle code texture, grid system, and connected nodes.
> Composition: clear left-to-right or bottom-to-top visual flow with stable balance.
> Color palette: dark background with cool blue/cyan lines and small green approval highlights.
> Mood: rational, engineering-driven, real project delivery story.
> Output constraints: high quality, no copyright-sensitive logos, no people, no readable text.
> Keywords: postmortem, software delivery, release pipeline, compliance review, process visualization.

## Prompt C (Product Value Style)
**Prompt:**
> Create a clean product-marketing style hero image showing the value of a developer tool successfully launched in an app store.
> Main elements: app window mockup, store card, abstract download arrow and success check graphics.
> Style: minimal, fresh, trustworthy, product-focused visual language.
> Layout: reserve generous whitespace for Chinese title overlay (top 25%, middle 20%).
> Color palette: white or light-gray base with blue primary tones and small green success accents.
> Output constraints: no specific brand logos, no readable UI copy, clean edges, soft shadows, suitable for WeChat article cover.
> Keywords: developer tools, distribution channel, store listing, successful launch, minimal tech illustration.
