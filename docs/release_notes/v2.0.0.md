# DistroNexus v2.0.0 Release Notes

**Release Date:** January 27, 2026

## 🎉 Major Rewrite: .NET 10 + WPF

DistroNexus 2.0.0 represents a complete architectural overhaul, migrating from the Go/Fyne stack to .NET 10 with WPF for a native Windows experience.

---

## ✨ What's New

### Modern Windows UI
- **WPF-UI Framework**: Fluent Design System with native Windows 11 styling
- **Dark Mode Support**: Automatic theme switching based on system preferences
- **Responsive Layout**: Optimized for high-DPI displays
- **Modern Controls**: Cards, expandable sections, and smooth animations

### PowerShell Module Architecture
- **Unified Module**: All 12 legacy scripts consolidated into `DistroNexus.psm1`
- **11 Cmdlets**: Full PowerShell integration for automation
  - `Get-WslInstance` - List all WSL instances
  - `Start-WslInstance` - Start instances
  - `Stop-WslInstance` - Stop instances
  - `Move-WslInstance` - Relocate instances
  - `Rename-WslInstance` - Rename instances
  - `Remove-WslInstance` - Uninstall instances
  - `Install-DistroNexusInstance` - Custom installation
  - `Set-WslCredentials` - Update credentials
  - `Get-DistroNexusPackage` - Browse available distributions
  - `Save-DistroNexusPackage` - Download distribution packages
  - `Update-DistroNexusCatalog` - Refresh catalog
- **Auto-Import**: Module loaded automatically on app startup
- **Logging System**: Integrated logging with rotation support

### Enhanced Features
- **Instance Management**: Start, stop, remove instances with one click
- **Package Manager**: Browse and download WSL distributions from catalog
- **Settings Page**: Comprehensive configuration options
  - Default installation path
  - WSL version preference
  - Download settings (concurrent downloads, retry logic)
  - Theme and language preferences
- **Progress Tracking**: Real-time progress for downloads and operations
- **Error Handling**: Graceful error messages with detailed logging

### Technical Improvements
- **.NET 10**: Latest .NET runtime for optimal performance
- **MVVM Pattern**: Clean separation of concerns with CommunityToolkit.Mvvm
- **Dependency Injection**: Microsoft.Extensions.DependencyInjection throughout
- **Async/Await**: Non-blocking UI with proper async patterns
- **Service Architecture**: Modular, testable service layer
  - PowerShellService - Execute cmdlets via runspaces
  - WslManagerService - High-level WSL operations
  - DownloadService - HTTP downloads with progress
  - SettingsService - JSON-based settings persistence
  - CatalogService - Distribution catalog management

## 📦 Installation

### Requirements
- Windows 10 version 2004 or later, or Windows 11
- .NET 10 Runtime (automatically installed by installer)
- WSL2 enabled (optional for setup, required for usage)

### Quick Start
1. Download `DistroNexus-2.0.0-Setup.exe`
2. Run the installer
3. Launch DistroNexus from Start Menu
4. Start managing your WSL instances!

### Portable Version
Download `DistroNexus-2.0.0-Portable.zip` for a no-install experience:
1. Extract to any folder
2. Run `DistroNexus.Desktop.exe`
3. All settings stored in `%APPDATA%\DistroNexus`

---

## 🔄 Migration from v1.x

### Automatic Migration
- Settings are NOT automatically migrated from v1.x
- You will need to reconfigure your preferences in Settings
- Existing WSL instances remain untouched and are detected automatically

### Breaking Changes
- ⚠️ **Go/Fyne UI removed**: Completely new .NET/WPF interface
- ⚠️ **Script-based → Module-based**: Legacy PowerShell scripts replaced with module
- ⚠️ **Configuration format**: Settings now stored in JSON at `%APPDATA%\DistroNexus\settings.json`

### What's Preserved
- ✅ All WSL instances managed by v1.x remain accessible
- ✅ Distribution catalog compatible with v1.x format
- ✅ Core functionality (install, manage, move instances) works identically

## 🛠️ PowerShell Module Usage

The PowerShell module can be used independently:

```powershell
# Import the module
Import-Module "C:\Program Files\DistroNexus\PowerShell\DistroNexus.psm1"

# List all instances
Get-WslInstance

# Start an instance
Start-WslInstance -DistroName "Ubuntu-22.04"

# Install a custom instance
Install-DistroNexusInstance -DistroName "MyUbuntu" -InstallPath "D:\WSL\MyUbuntu" -Username "admin"

# Browse available distributions
Get-DistroNexusPackage | Format-Table Name, Version, Category

# Get help for any cmdlet
Get-Help Install-DistroNexusInstance -Full
```

## 🐛 Known Issues

### PowerShell Integration
- First launch may take 3-5 seconds to initialize PowerShell runspace
- Some cmdlets require elevated privileges (will prompt via UAC)

### UI
- Settings page refresh button may not work on first click (refresh again)
- Instance list doesn't auto-refresh (use Refresh button)

### Compatibility
- Requires .NET 10 Desktop Runtime (not compatible with older .NET versions)
- Windows 10 1903 and earlier are not supported
