# DistroNexus v2.0.1 发布日志

**发布日期：** 2026-01-31

## 🎉 重大重构版本：.NET 10 + WPF

DistroNexus 2.0.1 是 v2 的首个正式版本，产品从 v1.x 分支（最新版本：v1.0.2）升级到基于 .NET 10 + WPF 的全新架构。

---

## ✨ v2 新增与升级

### 完整架构重构
- 桌面端 UI 从 Go/Fyne 全面迁移到原生 WPF
- 基于 .NET 10 的现代化应用技术栈
- 使用 CommunityToolkit.Mvvm 的 MVVM 架构
- 使用 Microsoft.Extensions.DependencyInjection 构建依赖注入体系
- 长耗时任务采用 async/await 异步执行模型

### 现代化 UI 与交互体验
- 基于 WPF-UI 的 Fluent Design 风格界面
- 支持深色模式与更一致的视觉主题
- 操作过程支持更清晰的状态与进度反馈
- 设置与诊断体验增强

### 日志与诊断
v2.0.1 在桌面端与 PowerShell 工作流中提供了统一日志能力，使问题排查更高效且更可预测。
日志写入路径为 `%APPDATA%\DistroNexus\logs`，可用于追踪安装、生命周期操作、包/目录更新与模板执行等流程。
诊断链路设计目标是提升问题复现能力，便于本地调试和支持场景定位。

### 产品与文档双语支持
v2.0.1 在 WPF 桌面客户端与项目文档中均提供英文与简体中文双语支持。
核心 UI 界面、发布说明与关键操作参考均提供双语内容，提升全球与中文用户可达性。
内容与本地化结构在多语言间保持一致，降低后续版本更新中的内容漂移风险。

### PowerShell 模块平台（15 个 Cmdlet）
PowerShell 模块为 DistroNexus 提供稳定且可脚本化的自动化命令面。
它既支持交互式运维，也支持团队环境初始化、CI 验证与本地开发环境引导等可重复工作流。
通过一致的 cmdlet 契约，用户可在统一接口下完成实例生命周期、包缓存、目录管理与模板自动化任务。

- 导出命令面（含简要说明）：
  - `Get-DistroNexusInstance`：列出已注册的 WSL 实例及其运行状态。
  - `Start-DistroNexusInstance`：启动指定 WSL 实例。
  - `Stop-DistroNexusInstance`：停止（终止）正在运行的 WSL 实例。
  - `Move-DistroNexusInstance`：将实例迁移到新磁盘/路径。
  - `Rename-DistroNexusInstance`：重命名已注册实例。
  - `Remove-DistroNexusInstance`：注销实例并可选删除相关文件。
  - `Install-DistroNexusInstance`：从目录/安装包源安装新的 WSL 实例。
  - `Set-DistroNexusCredential`：设置或重置实例默认用户凭据。
  - `Get-DistroNexusPackage`：列出可用或已缓存的发行版安装包。
  - `Save-DistroNexusPackage`：下载并缓存发行版安装包到本地。
  - `Remove-DistroNexusPackage`：删除本地缓存安装包文件。
  - `Update-DistroNexusCatalog`：从源刷新发行版目录元数据。
  - `Get-DistroNexusTemplate`：查询可用模板（支持筛选）。
  - `Apply-DistroNexusTemplate`：将模板应用到目标实例。
  - `Invoke-DistroNexusTemplateAutomation`：执行模板自动化验证工作流。

### 内置模板系统
模板系统为常见开发场景提供可复用的环境引导流程。
它将声明式元数据与脚本化执行结合，使团队可在多台机器间应用一致的环境标准。
通过参数化选项与自动化验证支持，模板系统可显著降低入门配置时间与环境漂移风险。
- 提供内置环境模板，快速完成开发环境初始化
- 模板元数据：`config/templates.json`
- 模板脚本资源：`config/templates/`
- 支持参数化模板执行与自动化验证流程
- 按分类提供的模板：
  - **Development**
    - `dotnet-dev` (.NET Development)
    - `nodejs-dev` (Node.js Development)
    - `python-dev` (Python Development)
    - `docker-dev` (Docker Development)
    - `fullstack-dev` (Fullstack Development)
    - `dotnet-multi-sdk-dev` (.NET Multi-SDK Development)
    - `nodejs-multi-version-dev` (Node.js Multi-Version Development)
    - `python-multi-version-dev` (Python Multi-Version Development)
    - `rust-dev` (Rust Development)
    - `go-dev` (Go Development)
  - **Platform**
    - `java-jvm-dev` (Java/JVM Development)
  - **CloudNative**
    - `container-runtime-dev` (Container Runtime Development)
    - `kubernetes-local-dev` (Kubernetes Local Development)
  - **Database**
    - `database-local-stack` (Database Local Stack)
  - **DataAndAI**
    - `ai-ml-gpu-dev` (AI/ML GPU Development)

### 目录与配置契约统一
- 发行版目录统一为 `catalog.json`
- 设置文件统一在 `%APPDATA%\DistroNexus\settings.json`
- 发布与运行时路径契约进一步一致化

### 仓库与发布清理
- 移除遗留 v1.0 Go/Fyne 源码与构建脚本
- 旧版独立 PowerShell 脚本迁移为模块化命令工作流
- 历史对比资料归档，仓库结构更清晰
- 模块/构建/安装器默认版本统一到 `2.0.1`

## 📦 安装方式

### 系统要求
- Windows 10 2004 及以上，或 Windows 11
- .NET 10 Desktop Runtime（安装器会处理运行时依赖）
- 已启用 WSL2（完整功能必需）

### 快速开始
1. 下载 `DistroNexus-2.0.1-Setup.exe`
2. 运行安装程序
3. 从开始菜单启动 DistroNexus

### 便携版
下载 `DistroNexus-v2.0.1-Release.zip`：
1. 解压到任意目录
2. 运行 `DistroNexus.Desktop.exe`

### 自包含版
下载 `DistroNexus-v2.0.1-Release-selfcontained.zip`：
1. 解压到任意目录
2. 运行 `DistroNexus.Desktop.exe`
