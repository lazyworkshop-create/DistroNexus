# DistroNexus v2.0.2 Release Notes

**Release Date:** 2026-02-18

This release focuses on improving the distribution catalog management and fixing issues with loading distribution lists.

## 🚀 Features

-   **Automated Catalog Updates**: The application now automatically syncs its distribution catalog with the official Microsoft WSL distribution list on each release unless a store build is performed.
-   **Enhanced Distro Discovery**: Improved logic for detecting available distributions, including better support for ARM64 architecture variants.

## 🐛 Bug Fixes

-   **Fixed**: "Property not found" errors when loading distribution lists that lacked local cache properties.
-   **Fixed**: Application now correctly falls back to valid local configuration if online update fails.
-   **Fixed**: Addressed an issue where `catalog.json` properties `IsCached` and `LocalPath` were missing in some scenarios.

## 📦 Improvements

-   **Configuration**: `catalog.json` is now tracked in the repository and updated automatically during the build process.
-   **Installer**: The installer now ensures the latest distribution catalog is deployed to the user's value configuration folder.
