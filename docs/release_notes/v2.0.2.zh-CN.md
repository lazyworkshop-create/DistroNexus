# DistroNexus v2.0.2 发布说明

**发布日期：** 2026-02-18

本次更新主要集中在改进发行版目录管理，并修复了加载发行版列表时的潜在问题。

## 🚀 新功能

-   **自动化目录更新**：应用现在会在每次非商店版本发布时，自动同步微软官方 WSL 发行版列表。
-   **增强的发行版发现**：改进了可用发行版的检测逻辑，包括对 ARM64 架构变体的更好支持。

## 🐛 错误修复

-   **修复**：修复了加载缺少本地缓存属性的发行版列表时出现的“属性未找到”错误。
-   **修复**：如果在线更新失败，应用现在能正确回退到有效的本地配置。
-   **修复**：解决了在某些情况下 `catalog.json` 缺少 `IsCached` 和 `LocalPath` 属性导致的问题。

## 📦 改进

-   **配置管理**：`catalog.json` 现在已被纳入版本控制，并在构建过程中自动更新。
-   **安装程序**：安装程序现在确保将最新的发行版目录部署到用户的配置文件夹中。
