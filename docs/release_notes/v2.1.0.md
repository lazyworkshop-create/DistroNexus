# Release Notes v2.1.0

Release date: 2026-02-19  
Range: `v2.0.3..v2.1.0`

## Highlights

- Template workflow reliability has been significantly hardened across wizard, core execution paths, and UI feedback.
- CI and quality gates now use explicit quick/full metadata scopes, plus a dedicated WSL2 validation lane.
- Download and package management UX now provides byte-level progress/speed visibility and clearer grouped package behavior.
- Release governance artifacts (checklists, evidence tracking, localization verification) are synchronized for acceptance readiness.

## Added

- Template-first startup support for install wizard and dedicated template options step.
- WSL2 capability-gated validation workflow (`.github/workflows/wsl-validation.yml`).
- UI automation coverage for package download flow and screenshot regression baseline checks.
- Quality remediation requirements/checklists and structured evidence tracking updates.

## Changed

- Download pipeline now exposes byte-level progress and speed metrics with aligned UI presentation.
- Package manager now groups same-file package variants for clearer install/download decisions.
- Quick/full test partitioning now uses explicit `TestScope` and PowerShell tag metadata.
- Localization verification checklist is closed with implementation/build evidence updates.

## Fixed

- Hardened template execution and package install flows in core workflow paths.
- Normalized package cache path and filename resolution in PowerShell module behavior.
- Corrected template-apply UI log level/toggle styling consistency.
