# 发布说明 v2.1.0

发布日期：2026-02-19  
变更范围：`v2.0.3..v2.1.0`

## 版本亮点

- 模版工作流在向导、核心执行链路和 UI 反馈上完成了系统性加固。
- CI 与质量门禁采用明确的快速/全量元数据分层，并新增 WSL2 专用验证通道。
- 下载与包管理体验升级：支持字节级进度/速度显示，并优化同文件包的分组展示。
- 发布治理文档（清单、证据追踪、本地化验证）已完成同步，满足验收准备要求。

## 新增

- 安装向导支持“模版优先”启动路径，并新增模版高级选项步骤。
- 新增 WSL2 能力门控验证工作流（`.github/workflows/wsl-validation.yml`）。
- 新增包下载流程 UI 自动化覆盖与截图回归基线能力。
- 新增质量整改需求/清单及结构化证据追踪更新。

## 变更

- 下载链路支持字节级进度与速度指标，并优化 UI 对齐展示。
- 包管理器支持同文件包变体分组，提升下载/安装决策清晰度。
- 快速/全量测试拆分改为显式 `TestScope`（C#）与 Tag（PowerShell）元数据策略。
- 本地化实时切换验证清单已基于实现与构建证据完成闭环。

## 修复

- 加固了核心工作流中的模版执行与安装流程稳定性。
- 修复 PowerShell 模块中的包缓存路径与文件名解析行为。
- 修复模版应用相关 UI 日志级别与切换控件样式一致性问题。
