# DistroNexus v2.1.1 Release Notes

**Release Date:** 2026-02-21

## Overview

DistroNexus v2.1.1 is a tooling and governance enhancement release focused on standardizing the release evidence pipeline, improving template metadata validation, and hardening automation regression testing. This release ensures that all future updates have deterministic, auditable artifacts and a robust sign-off workflow.

## Key Enhancements

### 1. Evidence Pipeline Standardization
- **Release Evidence Bundle Collector**: Introduced `New-DistroNexusReleaseEvidenceBundle` to automatically gather and package test results, lint reports, and regression diffs into a standardized JSON artifact (`SchemaVersion: '1.0'`).
- **Deterministic Artifacts**: Evidence generation now uses relative paths and stable naming conventions, ensuring that artifacts are identical whether generated locally or in CI environments.

### 2. Template Metadata Validation
- **Template Linter**: Added `Test-DistroNexusTemplateMetadata` to validate `templates.json` against a strict schema, ensuring all built-in templates meet quality standards before release.
- **Lint Reporting**: The linter outputs detailed JSON reports, which are now integrated into the release evidence bundle.

### 3. Automation Regression Hardening
- **Historical Regression Diffs**: `Invoke-DistroNexusTemplateAutomation` now generates historical regression diffs, allowing developers to track changes in template execution behavior over time.
- **Baseline Resolution**: Hardened the resolution and ordering of regression baselines to prevent false positives during automated testing.

## Governance and Tracking
- **Chronological Tracking**: Reorganized project tracking files (`task_plan.md`, `findings.md`, `progress.md`) chronologically to improve auditability and historical context.
- **Sign-off Workflows**: Formalized the release sign-off process with new handoff templates and reference indexes.

## Technical Details
- **PowerShell Module**: Version bumped to `2.1.1`.
- **.NET Client**: Version bumped to `2.1.1`.
- **Installer**: Version bumped to `2.1.1`.
