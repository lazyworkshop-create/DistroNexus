# DistroNexus v2.1.1 发行说明

**发布日期:** 2026-02-21

## 概述

DistroNexus v2.1.1 是一个专注于工具和治理增强的版本，主要目标是标准化发布证据管道、改进模板元数据验证以及强化自动化回归测试。此版本确保所有未来的更新都具有确定性、可审计的工件和稳健的签核工作流。

## 主要增强功能

### 1. 证据管道标准化
- **发布证据包收集器**: 引入了 `New-DistroNexusReleaseEvidenceBundle`，用于自动收集测试结果、lint 报告和回归差异，并将其打包成标准化的 JSON 工件 (`SchemaVersion: '1.0'`)。
- **确定性工件**: 证据生成现在使用相对路径和稳定的命名约定，确保无论是在本地还是在 CI 环境中生成的工件都是一致的。

### 2. 模板元数据验证
- **模板 Linter**: 添加了 `Test-DistroNexusTemplateMetadata`，用于根据严格的模式验证 `templates.json`，确保所有内置模板在发布前符合质量标准。
- **Lint 报告**: Linter 输出详细的 JSON 报告，这些报告现在已集成到发布证据包中。

### 3. 自动化回归强化
- **历史回归差异**: `Invoke-DistroNexusTemplateAutomation` 现在会生成历史回归差异，允许开发人员跟踪模板执行行为随时间的变化。
- **基线解析**: 强化了回归基线的解析和排序，以防止在自动化测试期间出现误报。

## 治理和跟踪
- **按时间顺序跟踪**: 按时间顺序重新组织了项目跟踪文件 (`task_plan.md`, `findings.md`, `progress.md`)，以提高可审计性和历史上下文。
- **签核工作流**: 通过新的交接模板和参考索引正式化了发布签核流程。

## 技术细节
- **PowerShell 模块**: 版本升级到 `2.1.1`。
- **.NET 客户端**: 版本升级到 `2.1.1`。
- **安装程序**: 版本升级到 `2.1.1`。
