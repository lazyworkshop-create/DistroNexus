# DistroNexus v2.2.0 Release Notes

**Release Date:** 2026-03-02

## Overview

DistroNexus v2.2.0 is the **Deep Instance Management** release. It expands the existing lifecycle operations into a comprehensive operational capability, adding two major features and nine targeted enhancements across backup workflows, configuration visibility, network diagnostics, organisation tooling, and internal architecture. The PowerShell module grows from 15 to 36 exported cmdlets.

## New Features

### F-01 — VHDX Disk Compaction

New `Compress-DistroNexusInstance` cmdlet compacts the VHDX disk of a WSL instance to reclaim unused space.

- Runs `fstrim -av` inside the instance to zero deleted blocks before compaction.
- Uses `Optimize-VHD -Mode Full` (Hyper-V) when available; falls back to `diskpart compact vdisk`.
- Supports `-WhatIf` for a dry-run space estimate without modifying the disk.
- Auto-stops a running instance before compaction and restarts it afterwards.
- Requires administrator elevation for the `diskpart` fallback path.

### F-02 — Docker Desktop Integration Management

Three new cmdlets manage Docker Desktop WSL backend integration:

- `Get-DistroNexusDockerIntegration` — reports integration status for all instances.
- `Enable-DistroNexusDockerIntegration` — enables Docker backend for an instance.
- `Disable-DistroNexusDockerIntegration` — disables Docker backend for an instance.

Guards against WSL v1 instances and reserved distros (`docker-desktop`, `docker-desktop-data`). Reads and writes `integratedWslDistros` in Docker's `settings-store.json` (4.30+) with a fallback to `settings.json`.

## Enhancements

### E-01 — Instance Export and Import

- `Export-DistroNexusInstance` exports a running or stopped instance to a `.tar` archive. Supports `-Force` to auto-stop a running instance.
- `Import-DistroNexusInstance` imports a `.tar` archive as a new instance. Validates that the target name is not already registered.

### E-02 — Global `.wslconfig` Editor

- `Get-DistroNexusWslConfig` reads the global `~/.wslconfig` file and returns structured configuration.
- `Set-DistroNexusWslConfig` updates individual keys while preserving unknown keys and comments. Issues a warning when `Memory` exceeds 80 % of host RAM.

### E-03 — Instance-Level Resource Configuration

- `Get-DistroNexusInstanceConfig` reads per-instance sparse VHDX mode and exposes global memory/CPU settings from `.wslconfig`.
- `Set-DistroNexusInstanceSparseMode` enables or disables sparse VHDX mode via `wsl --manage`. Guards against WSL v1 instances.

### E-04 — Instance Backup Scheduling

Four cmdlets manage scheduled automated backups via Windows Task Scheduler:

- `New-DistroNexusBackupSchedule` — create a schedule (Daily / Weekly / Monthly).
- `Remove-DistroNexusBackupSchedule` — remove an existing schedule.
- `Get-DistroNexusBackupSchedule` — list configured schedules.
- `Invoke-DistroNexusBackup` — run a backup on demand; handles stop/export/restart lifecycle and enforces retention.

### E-05 — Port Forwarding Visualization

`Get-DistroNexusPortMapping` visualizes all listening ports inside a WSL instance. Parses `ss` output, cross-references `netsh portproxy` rules, and returns WSL IP address alongside each mapping.

### E-06 — Instance Tagging and Grouping

Four cmdlets manage per-instance tags:

- `Get-DistroNexusInstanceTag`, `Set-DistroNexusInstanceTag`, `Add-DistroNexusInstanceTag`, `Remove-DistroNexusInstanceTag`.

Tags are case-insensitively normalised, limited to 10 per instance, and persisted in `%APPDATA%\DistroNexus\settings.json`.

### E-07 — Proactive Cache Invalidation

`WslEventWatcher` monitors WSL process events with a 2-second debounce timer and automatically invalidates the instance cache after detected changes. A new `Get-DistroNexusCache` diagnostic cmdlet exposes cache age, entry count, and staleness state.

### E-08 — Decouple PowerShell Service Layer

`WslCliRunner` wraps direct `wsl.exe` process invocations. `WslManagerService` now uses native `wsl --list --verbose` parsing (Phase 1) when `IWslCliRunner` is injected, eliminating one PowerShell process spin-up per instance-list operation.

### E-09 — Unified Error Code System

`DistroNexusErrorCode` enum defines stable numeric error codes across all categories:

| Range | Category |
|-------|----------|
| 1xxx  | Instance lifecycle |
| 2xxx  | Disk / VHDX |
| 3xxx  | Docker integration |
| 4xxx  | Backup / export / import |
| 5xxx  | Configuration |
| 9xxx  | System / unknown |

All exception subclasses now carry a typed `Code` property. See [`docs/development/error-codes.md`](../development/error-codes.md) for the full reference table.
