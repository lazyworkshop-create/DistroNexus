# DistroNexus v2.2.0 发行说明

**发布日期：** 2026-03-02

## 概述

DistroNexus v2.2.0 是**深度实例管理**版本。本次发布将现有的基础生命周期操作升级为完整的运营能力，新增两项主要功能和九项专项增强，覆盖备份工作流、配置可见性、网络诊断、组织工具及内部架构改进。PowerShell 模块导出命令数量从 15 个增长至 36 个。

## 新功能

### F-01 — VHDX 磁盘压缩

新命令 `Compress-DistroNexusInstance` 可压缩 WSL 实例的 VHDX 磁盘以回收未使用空间。

- 在压缩前在实例内部执行 `fstrim -av` 将已删除块清零。
- 优先使用 `Optimize-VHD -Mode Full`（Hyper-V），不可用时回退至 `diskpart compact vdisk`。
- 支持 `-WhatIf` 参数进行空间估算演练，不实际修改磁盘。
- 自动停止正在运行的实例，压缩完成后自动重启。
- `diskpart` 回退路径需要管理员权限。

### F-02 — Docker Desktop 集成管理

三个新命令管理 Docker Desktop WSL 后端集成：

- `Get-DistroNexusDockerIntegration` — 查看所有实例的集成状态。
- `Enable-DistroNexusDockerIntegration` — 为指定实例启用 Docker 后端。
- `Disable-DistroNexusDockerIntegration` — 为指定实例禁用 Docker 后端。

自动防止 WSL v1 实例和保留发行版（`docker-desktop`、`docker-desktop-data`）被操作。读写 Docker `settings-store.json`（4.30+）中的 `integratedWslDistros`，并回退至 `settings.json`。

## 增强功能

### E-01 — 实例导出与导入

- `Export-DistroNexusInstance`：将实例导出为 `.tar` 归档文件。支持 `-Force` 自动停止运行中的实例。
- `Import-DistroNexusInstance`：将 `.tar` 归档导入为新实例。会验证目标名称未被占用。

### E-02 — 全局 `.wslconfig` 编辑器

- `Get-DistroNexusWslConfig`：读取全局 `~/.wslconfig` 文件并以结构化形式返回配置。
- `Set-DistroNexusWslConfig`：更新指定键值，同时保留未知键和注释。当 `Memory` 超过主机 RAM 的 80% 时发出警告。

### E-03 — 实例级资源配置

- `Get-DistroNexusInstanceConfig`：读取实例的稀疏 VHDX 模式，并展示 `.wslconfig` 中的全局内存/CPU 设置。
- `Set-DistroNexusInstanceSparseMode`：通过 `wsl --manage` 启用或禁用稀疏 VHDX 模式。自动拒绝 WSL v1 实例。

### E-04 — 实例备份调度

四个命令通过 Windows 任务计划程序管理自动备份：

- `New-DistroNexusBackupSchedule` — 创建调度计划（每日/每周/每月）。
- `Remove-DistroNexusBackupSchedule` — 删除现有计划。
- `Get-DistroNexusBackupSchedule` — 列出已配置的计划。
- `Invoke-DistroNexusBackup` — 立即执行备份；自动处理停止/导出/重启生命周期并执行保留策略。

### E-05 — 端口转发可视化

`Get-DistroNexusPortMapping` 可视化 WSL 实例内的所有监听端口。解析 `ss` 输出，关联 `netsh portproxy` 规则，并返回 WSL IP 地址及每条映射详情。

### E-06 — 实例标签与分组

四个命令管理实例标签：

- `Get-DistroNexusInstanceTag`、`Set-DistroNexusInstanceTag`、`Add-DistroNexusInstanceTag`、`Remove-DistroNexusInstanceTag`。

标签不区分大小写，每个实例最多 10 个，持久化存储于 `%APPDATA%\DistroNexus\settings.json`。

### E-07 — 主动缓存失效

`WslEventWatcher` 以 2 秒防抖时窗监控 WSL 进程事件，检测到变化后自动使实例缓存失效。新增诊断命令 `Get-DistroNexusCache`，可查看缓存年龄、条目数量及失效状态。

### E-08 — 解耦 PowerShell 服务层

`WslCliRunner` 封装了对 `wsl.exe` 进程的直接调用。注入 `IWslCliRunner` 后，`WslManagerService` 将使用原生 `wsl --list --verbose` 解析（阶段一），减少每次实例列表操作的 PowerShell 进程开销。

### E-09 — 统一错误码系统

`DistroNexusErrorCode` 枚举为所有类别定义了稳定的数字错误码：

| 范围 | 类别 |
|------|------|
| 1xxx | 实例生命周期 |
| 2xxx | 磁盘 / VHDX |
| 3xxx | Docker 集成 |
| 4xxx | 备份 / 导出 / 导入 |
| 5xxx | 配置 |
| 9xxx | 系统 / 未知 |

所有异常子类现在均携带类型化的 `Code` 属性。完整参考表请见 [`docs/development/error-codes.md`](../development/error-codes.md)。
