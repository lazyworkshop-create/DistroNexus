# DistroNexus v2.2.1 Release Notes

**Release Date:** 2026-07-05

## Overview

DistroNexus v2.2.1 is the **v2.2.0 completion release**. It closes the remaining desktop, reliability, and diagnostics gaps from the deep instance management work without expanding the product scope beyond the v2.2.0 commitments.

The release focuses on making already-built backend capabilities fully usable from the desktop app: instance detail tabs, disk compaction flows, Docker and network diagnostics, backup scheduling and history, WSL configuration controls, tag management, export/import hardening, structured errors, and localization.

## User-Facing Improvements

### Instance Detail Experience

- Added a desktop detail surface for per-instance management.
- Exposed disk, resources, integrations, network, and backup controls through focused tabs.
- Hid the integrations tab when integration features are not available for the selected instance.
- Ensured tab-level operations set shared busy state so long-running actions are visible and guarded.

### Disk Compaction

- Added bulk disk compaction confirmation and cancellation support.
- Fixed compaction state cleanup so what-if, failure, and cancellation paths no longer leave the UI stuck in a busy state.
- Improved result handling for disk compaction operations.

### Export and Import

- Exporting a running instance now prompts and stops the instance before export when confirmed.
- Added export progress feedback with elapsed time and output file size polling.
- Added cancellation support for export progress.
- Improved import/export error reporting with structured alert formatting.

### Backup Management

- Backup history now combines successful backup files and pending failure notifications for the selected instance.
- Failed backups now display an error-aware history entry instead of disappearing from the UI.
- Backup history entries now have display names suitable for both file-backed and failure-backed records.

### Tags, Templates, and Dashboard Text

- Completed remaining dashboard and template string localization.
- Replaced hard-coded desktop UI strings with resource-backed English and zh-CN translations.
- Improved tag, template, and dashboard action text consistency.

## Error Handling and Diagnostics

### Structured Core Errors

- Converted ordinary service-layer failures to typed `WslOperationException` derivatives with `DistroNexusErrorCode` values.
- Expanded the error-code catalog for install, backup, PowerShell, and lifecycle failures.
- Verified all PowerShell `DistroNexus.*` `Write-Error -ErrorId` values have matching C# error-code enum entries.
- Preserved friendly installation failure messages while returning structured error codes.

### Error Dialog UX

- Error dialogs now display `[DN-XXXX]` when a structured error code is available.
- Added a copy-code action for dialogs that contain a DistroNexus error code.
- Applied structured alert formatting across instance detail tabs, WSL configuration, import/export, and backup flows.

## Reliability Fixes

- Fixed busy-state cleanup in disk tab compaction flows.
- Fixed cache TTL test isolation so tests no longer read or mutate the user's real AppData cache.
- Updated integration tests to assert the new typed error model.
- Kept install failure mapping user-friendly for catalog misses and missing downloaded files.

## Documentation

- Updated `docs/development/error-codes.md` with new and clarified error codes.
- Updated English and zh-CN release notes.
- Updated the website release post and installation asset references for v2.2.1.
