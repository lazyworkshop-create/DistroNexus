# DistroNexus v2.2.1 发行说明

**发布日期：** 2026-07-05

## 概述

DistroNexus v2.2.1 是 **v2.2.0 的完成版发布**。本版本不扩展 v2.2.0 之外的新方向，而是收敛深度实例管理工作中剩余的桌面端、可靠性和诊断缺口。

本次重点是让已经存在的后端能力完整落到桌面应用中：实例详情标签页、磁盘压缩流程、Docker 与网络诊断、备份计划与历史、WSL 配置控制、标签管理、导入导出加固、结构化错误和本地化。

## 用户可见改进

### 实例详情体验

- 新增面向单个实例的桌面详情管理界面。
- 通过聚焦的标签页暴露磁盘、资源、集成、网络和备份控制。
- 当所选实例不适用集成功能时，隐藏集成标签页。
- 标签页内的长耗时操作会设置共享 busy 状态，避免用户误以为操作没有开始或可以重复触发。

### 磁盘压缩

- 新增批量磁盘压缩确认与取消支持。
- 修复 what-if、失败和取消路径下压缩状态清理不完整的问题，避免 UI 卡在 busy 状态。
- 改进磁盘压缩结果处理。

### 导出与导入

- 导出运行中的实例时，现在会提示用户，并在确认后先停止实例再导出。
- 新增导出进度反馈，包含耗时与输出文件大小轮询。
- 导出进度支持取消。
- 导入导出错误现在使用结构化提示格式。

### 备份管理

- 备份历史现在会合并展示所选实例的成功备份文件和待处理失败通知。
- 失败备份会作为带错误信息的历史记录显示，而不是从 UI 中消失。
- 备份历史记录新增适用于文件记录和失败记录的显示名称。

### 标签、模板和仪表盘文案

- 补齐仪表盘与模板相关的剩余本地化文案。
- 将硬编码桌面 UI 字符串替换为资源文件中的英文和简中翻译。
- 改进标签、模板和仪表盘操作文案的一致性。

## 错误处理与诊断

### 结构化 Core 错误

- 将服务层普通失败转换为带 `DistroNexusErrorCode` 的 `WslOperationException` 派生类型。
- 扩展安装、备份、PowerShell 和生命周期相关错误码。
- 验证所有 PowerShell `DistroNexus.*` `Write-Error -ErrorId` 都能在 C# 错误码枚举中找到对应项。
- 保留安装失败时的用户友好提示，同时返回结构化错误码。

### 错误对话框体验

- 当存在结构化错误码时，错误对话框会显示 `[DN-XXXX]`。
- 对包含 DistroNexus 错误码的对话框新增复制错误码操作。
- 实例详情标签页、WSL 配置、导入导出和备份流程均已采用结构化错误提示格式。

## 可靠性修复

- 修复磁盘标签页压缩流程中的 busy 状态清理问题。
- 修复缓存 TTL 测试隔离问题，避免测试读取或修改用户真实 AppData 缓存。
- 更新集成测试以验证新的 typed error 模型。
- 保持目录缺失和下载文件缺失场景下的安装失败提示对用户友好。

## 文档

- 更新 `docs/development/error-codes.md`，补充并澄清错误码。
- 更新英文和简中发行说明。
- 更新网站发布文章和 v2.2.1 安装资产引用。
