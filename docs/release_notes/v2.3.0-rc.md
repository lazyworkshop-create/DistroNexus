# DistroNexus v2.3.0 Release Candidate

## Repository status

This document records the v2.3.0 repository release candidate. It is not an announcement of a published package.

The release adds the Health Center, lossless WSL configuration, recovery points, monitoring, systemd and networking controls, USB ownership controls, trusted workspaces, WSLg application discovery, container runtime inventory, and the trusted template marketplace.

## Upgrade from v2.2.1

- Existing settings, tags, backup schedules, template metadata, and instance registrations remain readable.
- New JSON stores use versioned envelopes and migrate legacy data on the next successful write.
- Remote templates require review and trust; local v2.2.1 templates retain the documented local-template policy.
- No WSL distribution, Windows feature, container runtime, USB device, or remote source is changed by upgrade alone.

## External acceptance gates

The following evidence is intentionally not claimed by this repository candidate:

- Supported Windows, WSL, and distribution matrix on x64 and ARM64.
- Docker Desktop, Podman, WSLg, and VS Code reference-version acceptance.
- Physical USB and privileged helper acceptance.
- Signed installer identity, upgrade package behavior, Store-mode validation, publication, and rollback rehearsal.

See [the v2.3.0 requirements](../specs/v2.3.0-requirements.md) and [design open items](../specs/v2.3.0-design.md) for owners and closure actions.
