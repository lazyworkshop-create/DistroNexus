# DistroNexus v2.3.0

## Highlights

- Adds Health Center diagnostics and guided repair, lossless WSL configuration, recovery points, and bounded instance monitoring.
- Adds systemd and networking controls, guarded USB ownership workflows, trusted development workspaces, WSLg application discovery, and read-only container-runtime inventory.
- Adds a PowerShell-first automation surface for shipped product operations, with the WPF client acting as an interaction layer.
- Adds trusted template marketplace and application workflows with explicit review, capability, and recovery boundaries.

## Upgrade from v2.2.1

- Existing settings, tags, backup schedules, template metadata, and instance registrations remain readable.
- New JSON stores use versioned envelopes and migrate legacy data on the next successful write.
- Remote templates require review and trust; local v2.2.1 templates retain the documented local-template policy.
- Upgrading alone does not change WSL distributions, Windows features, container runtimes, USB devices, or remote sources.

## Validation boundaries

Repository CI passed for the merged v2.3.0 baseline. Before publishing the final tag, the final release-preparation commit must complete its release workflow. The release evidence record separately tracks environment-owned validation, including Windows/WSL hardware matrices, optional-product integrations, signed installer upgrades, Store behavior, publication, and rollback rehearsal.

See the [v2.3.0 release evidence record](../development/v2.3.0-release-evidence-record.md) for the current gate status.
