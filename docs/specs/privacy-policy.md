# DistroNexus Privacy Policy (Draft)

Date: 2026-02-15
Scope: Desktop application and Store listing compliance reference.

## Data We Process
- DistroNexus stores user settings locally on the device in the user profile (`AppData\\Roaming\\DistroNexus`).
- DistroNexus stores local template and catalog cache data for runtime convenience.
- DistroNexus executes local system commands required for WSL management.

## Network Access
- DistroNexus may download catalog or template content from configured sources.
- DistroNexus does not require account sign-in to run core local workflows.
- DistroNexus does not include in-app purchases.

## Local Processing Statement
- WSL management operations are initiated by the user and executed locally.
- Runtime command execution and generated outputs remain on the user device unless the user exports/shares data.

## Data Sharing
- DistroNexus does not intentionally sell personal data.
- DistroNexus does not intentionally transmit personal content except requests initiated by the user (for example configured remote catalog/template endpoints).

## Data Retention and Deletion
- Settings and cache files remain on-device until the user removes them or uninstalls the app.
