# v2.2.0 Gap Fixes — Phase 1 (Backend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all 22 backend/PowerShell gaps from the v2.2.0 gap audit so every non-UI requirement item is fully implemented.

**Architecture:** Each task maps to one GAP-* entry from the audit spec and produces one atomic commit. Ordered so dependencies come first (typed exceptions before error display; event wiring before WMI). No task touches the Desktop UI layer.

**Tech Stack:** C# 12 / .NET 10, PowerShell 7, Pester 5, xUnit + Moq, Microsoft.Win32.Registry, System.Management (WMI).

**Spec:** `docs/superpowers/specs/2026-03-21-v2.2.0-gap-audit-design.md`
