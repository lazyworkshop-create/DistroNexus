# v2.2.0 Requirements Gap Audit Design

**Date**: 2026-03-21
**Branch**: feat/v2.2.0
**Spec Reference**: [docs/specs/v2.2.0-requirements.md](../../specs/v2.2.0-requirements.md)

---

## Overview

Full audit of every requirement sub-item in the v2.2.0 spec (F-01 through E-09, ~75 items) against the current codebase. The backend (PowerShell cmdlets + C# service layer) is largely complete. The primary gap pattern is:

1. **Desktop UI layer is entirely absent for all 11 features** — no instance detail panel, no new tabs, no context-menu items, no status columns were ever added to `MainWindow.xaml`.
2. **E-09 throw-site and display wiring** — typed exception classes exist but services throw generic `InvalidOperationException`; UI dialogs show no error codes; `Logger.ps1` has no error code field; most cmdlets lack `Write-Error -ErrorId` usage.
3. **E-08 Phase 2/3 gaps** — disk-size (`FileInfo.Length`) and state-polling (`wsl --list --running`) native paths not implemented; registry reads still PowerShell-based.
4. **Cross-cutting backend gaps** — tag 32-char validation, tag lifecycle hooks (rename/remove), Docker restart prompt, cache event wiring, processors validation, etc.

This document records all gaps and drives the fix plan.

### Phase 2 — UI layer

All 16 UI gaps share the same missing infrastructure: an instance detail panel and new tabs. These will be addressed as part of a single structural UI addition. The Phase 1 backend work must be complete before Phase 2 begins.
