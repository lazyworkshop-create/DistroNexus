We have released **DistroNexus v2.0.3** as a critical hotfix to address a configuration issue affecting distribution catalog updates.

<!--truncate-->

## Key Changes

### 🔧 Critical Fixes

-   **Catalog URL Correction**: Fixed a configuration error where the distribution catalog URL pointed to a non-existent `main` branch instead of the correct `master` branch. This ensures reliable catalog updates for all users.

## Updating

This is a **recommended update** for all v2.0.x users to ensure continued access to distribution updates. You can update via the in-app updater or download the installer from [GitHub Releases](https://github.com/lazyworkshop-create/DistroNexus/releases).
