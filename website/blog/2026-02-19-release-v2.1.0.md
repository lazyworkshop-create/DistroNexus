We are releasing **DistroNexus v2.1.0**, a quality and workflow hardening release focused on template reliability, test confidence, and release governance readiness.

<!--truncate-->

## Highlights

- Strengthened template execution and install reliability across core and wizard flows.
- Added explicit quick/full test scope strategy in CI and a dedicated WSL2 validation lane.
- Improved package download UX with byte-level progress/speed and same-file package grouping.
- Synchronized release governance artifacts (checklists, evidence tracking, localization verification).
