DistroNexus v2.2.1 is a focused quality patch that closes all remaining architectural gaps from the v2.2.0 deep-instance-management release. No new features — just better error handling, reliability fixes, and full localization coverage.

<!--truncate-->

## What's in v2.2.1?

### Structured Error Code Dialogs

Every error dialog now displays a `[DN-XXXX]` code when a structured `WslOperationException` is thrown. A new **"Copy error code"** hyperlink lets you copy the code when reporting issues. Five new error codes were added:

- `TooManyTags (1005)`, `ScheduleNotFound (4005)`, `TemplateNotFound (6001)`, `TemplateScriptFailed (6002)`, `PowerShellModuleUnavailable (9004)`

### Architecture Fixes

- **WMI event-watcher lifecycle**: `WslEventWatcher` is now properly disposed from both `WslManagerService` and `MainViewModel`, preventing background thread leaks.
- **Race condition fix**: the event watcher `Start()` is deferred until after the initial instance list loads.
- **Native registry reads**: `RenameInstanceAsync` no longer spawns a secondary PowerShell process to look up install paths — it now reads directly from the Windows registry.

### Complete Localization

All remaining hardcoded English strings in ViewModels and XAML views have been replaced with `Resources.resx` keys with zh-CN translations. `TemplatesPage.xaml` uses `{lex:Loc ...}` bindings throughout.

### PowerShell Error IDs

All public cmdlet `Write-Error` calls now include `-ErrorId "DistroNexus.<Code>"` for structured error tracing in PS error streams.
