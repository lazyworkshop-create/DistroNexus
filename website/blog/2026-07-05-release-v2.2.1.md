DistroNexus v2.2.1 is the completion release for v2.2.0. It brings the remaining deep instance management capabilities into the desktop app and finishes the reliability, diagnostics, and localization work needed to make the release line feel complete.

<!--truncate-->

## What's in v2.2.1?

### Desktop Instance Management

The desktop app now exposes the v2.2.0 backend capabilities through a richer instance detail experience:

- Disk, resources, integrations, network, and backup tabs for each instance.
- Bulk disk compaction confirmation and cancellation.
- Safer compaction state cleanup for what-if, failure, and cancellation paths.
- WSL configuration and tag-management text aligned with the rest of the desktop UI.

### Export, Import, and Backup UX

Long-running workflows now give clearer feedback:

- Exporting a running instance prompts before stopping it for export.
- Export progress shows elapsed time and output file growth.
- Backup history includes both successful backup files and failure entries for the selected instance.
- Import, export, backup, and tab-level errors use the same structured alert format.

### Structured Errors

Core services now return typed `WslOperationException` failures with `DistroNexusErrorCode` values instead of generic exceptions. Error dialogs display `[DN-XXXX]` codes and offer a copy-code action when a structured code is available.

Install failures keep their friendly messages while also carrying structured error codes, making issues easier to report and easier to diagnose.

### Localization and Polish

Remaining hard-coded desktop strings were moved into resource files with English and zh-CN coverage. This includes dashboard, template, progress, retry, and bulk compaction text.

## Validation

The release candidate passed Debug and Release builds, non-Full tests, Full non-UI integration tests, UI automation smoke tests, ViewModel tests, and PowerShell unit tests on 2026-07-05.
