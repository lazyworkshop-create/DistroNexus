# DistroNexus Privacy Policy

Effective Date: 2026-02-16
Product: DistroNexus desktop application for Windows.

## Overview
DistroNexus is a local-first Windows application for managing Windows Subsystem for Linux (WSL) distributions and applying development templates. Most operations are executed on the user device.

## Information We Process
DistroNexus may process the following categories of data:
- Application settings and preferences stored locally under `AppData\\Roaming\\DistroNexus`.
- Local cache files (for example catalog and template metadata) used to improve startup and offline usability.
- User-triggered operational data required to perform WSL management actions (for example instance names and command parameters).
- Command output and logs generated by local execution flows.

## How We Use Information
We use this information only to:
- Provide requested WSL management and template automation features.
- Store user preferences and improve local app usability.
- Display execution progress, status, and diagnostics.

## Local Processing and Device Access
- DistroNexus invokes local Windows and WSL tooling (including `wsl.exe`) when the user starts related actions.
- These actions are performed on-device and are not designed to require user account sign-in.

## Network Access
- DistroNexus may access network resources to download catalog/template content from configured endpoints.
- Network access depends on user configuration and feature usage.
- DistroNexus does not provide in-app purchases.

## Data Sharing
- DistroNexus does not intentionally sell personal data.
- DistroNexus does not intentionally transmit user personal content to third parties, except when explicitly required by user-configured endpoints or user-initiated operations.

## Data Retention and Deletion
- Local settings, cache, and logs remain on the device until changed or removed by the user.
- Users can remove local data by deleting app data files or uninstalling the application.

## Children
DistroNexus is a developer utility and is not directed to children.

## Security
We take reasonable measures in application design to reduce unnecessary data exposure. However, no software system can guarantee absolute security.

## Changes to This Policy
This policy may be updated from time to time. Material changes should be reflected by updating the effective date.
