DistroNexus v2.2.1 是一个专注于质量改进的补丁版本，填补了 v2.2.0 深度实例管理版本中所有遗留的架构空白。本次无新增功能，仅带来更完善的错误处理、可靠性修复和完整的本地化覆盖。

<!--truncate-->

## v2.2.1 包含哪些内容？

### 结构化错误代码对话框

每个错误对话框在抛出结构化 `WslOperationException` 时，现在均会显示 `[DN-XXXX]` 代码。新增的**"复制错误代码"**超链接可在报告问题时一键复制代码。新增五个错误代码：

- `TooManyTags (1005)`、`ScheduleNotFound (4005)`、`TemplateNotFound (6001)`、`TemplateScriptFailed (6002)`、`PowerShellModuleUnavailable (9004)`

### 架构修复

- **WMI 事件监视器生命周期**：`WslEventWatcher` 现在可从 `WslManagerService` 和 `MainViewModel` 两个路径正确释放，防止后台线程泄漏。
- **竞态条件修复**：事件监视器的 `Start()` 延迟至初始实例列表加载完成后才启动。
- **原生注册表读取**：`RenameInstanceAsync` 不再启动次级 PowerShell 进程来查找安装路径，现在直接从 Windows 注册表读取。

### 完整本地化

ViewModel 和 XAML 视图中所有剩余的硬编码英文字符串均已替换为具有简中翻译的 `Resources.resx` 键。`TemplatesPage.xaml` 全面采用 `{lex:Loc ...}` 绑定。

### PowerShell 错误 ID

所有公开命令的 `Write-Error` 调用现均包含 `-ErrorId "DistroNexus.<Code>"`，以便在 PS 错误流中进行结构化错误追踪。
