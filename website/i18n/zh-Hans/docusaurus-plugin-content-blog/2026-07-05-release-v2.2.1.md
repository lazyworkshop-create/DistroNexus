DistroNexus v2.2.1 是 v2.2.0 的完成版发布。本次将深度实例管理中剩余的能力补齐到桌面应用，并完成可靠性、诊断和本地化收尾，让 v2.2 发布线真正闭环。

<!--truncate-->

## v2.2.1 包含哪些内容？

### 桌面端实例管理

桌面应用现在通过更完整的实例详情体验暴露 v2.2.0 后端能力：

- 每个实例都有磁盘、资源、集成、网络和备份标签页。
- 批量磁盘压缩支持确认和取消。
- what-if、失败和取消路径下的压缩状态清理更加可靠。
- WSL 配置和标签管理文案与桌面 UI 其他部分保持一致。

### 导出、导入和备份体验

长耗时流程现在提供更清晰的反馈：

- 导出运行中的实例时，会先提示并在确认后停止实例再导出。
- 导出进度会显示耗时和输出文件大小变化。
- 备份历史同时展示成功备份文件和所选实例的失败记录。
- 导入、导出、备份和标签页操作错误使用统一的结构化提示格式。

### 结构化错误

Core 服务现在会返回带 `DistroNexusErrorCode` 的 typed `WslOperationException`，不再依赖普通泛型异常。错误对话框会显示 `[DN-XXXX]`，并在可用时提供复制错误码操作。

安装失败仍保留用户友好提示，同时携带结构化错误码，方便报告问题和定位原因。

### 本地化与打磨

剩余硬编码桌面字符串已迁移到资源文件，并补齐英文和简中覆盖，包括仪表盘、模板、进度、重试和批量压缩相关文案。

## 验证

该发布候选已于 2026-07-05 通过 Debug 和 Release 构建、非 Full 测试、Full 非 UI 集成测试、UI 自动化 smoke 测试、ViewModel 测试和 PowerShell 单元测试。

完整验证清单请参阅 [v2.2.1 发行说明](https://github.com/LazyWorkshopCreate/DistroNexus/blob/master/docs/release_notes/v2.2.1.zh-CN.md)。
