# 模板系统

本模块是 DistroNexus 模板系统完整文档的独立入口。

## 模块概览

模板系统为常见开发场景提供可复用的环境引导流程，包含：

- 内置模板元数据与脚本资源
- 参数化执行模型
- 桌面端流程集成
- PowerShell 自动化与验证支持
