# 介绍

**DistroNexus** 是面向 Windows 的 WSL 管理器，基于 **.NET 10 + WPF** 构建，并提供模块化 PowerShell 命令平台。

它为 Windows 10/11 提供安装、管理与自动化 WSL 环境的一体化桌面体验。

## 为什么选择 DistroNexus？

Windows Subsystem for Linux (WSL) 功能强大，但如果仅依赖命令行，在多实例管理、自定义磁盘布局与可重复交付方面会逐步变得复杂。

DistroNexus 通过提供以下功能解决了这个问题：

*   **原生 Windows 体验**：WPF 界面提供更清晰的诊断和进度反馈。
*   **完整生命周期管理**：安装、启动、停止、移动、重命名、移除、打开终端与凭据管理。
*   **双语体验**：WPF 客户端界面与项目文档均支持英文与简体中文。
*   **模块化自动化**：通过稳定 cmdlet 接口支持脚本化与团队协作。
*   **模板化引导**：内置模板可快速搭建常见开发环境。

## 核心功能

*   **原生 WPF 仪表盘**：基于 .NET 10 的现代 Windows 桌面体验。
*   **产品与文档双语支持**：客户端与文档统一支持英文 + 简体中文。
*   **PowerShell 模块平台**：统一的 15 条导出 cmdlet 命令面。
*   **模板系统**：内置环境模板与自动化工作流。
*   **灵活分发**：支持安装包、便携包、自包含包。
*   **运行可观测性**：长任务状态与进度反馈更清晰。
