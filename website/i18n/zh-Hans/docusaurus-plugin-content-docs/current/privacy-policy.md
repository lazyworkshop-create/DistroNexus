# DistroNexus 隐私政策

生效日期：2026-02-16  
产品：适用于 Windows 的 DistroNexus 桌面应用。

## 概述
DistroNexus 是一款本地优先的 Windows 应用，用于管理 Windows Subsystem for Linux（WSL）发行版并应用开发模板。大多数操作均在用户设备本地执行。

## 我们处理的信息
DistroNexus 可能处理以下类别的信息：
- 存储在 `AppData\\Roaming\\DistroNexus` 下的应用设置与偏好。
- 用于提升启动速度和离线可用性的本地缓存文件（例如目录与模板元数据）。
- 执行 WSL 管理操作所需的用户触发数据（例如实例名称与命令参数）。
- 本地执行流程产生的命令输出与日志。

## 信息用途
我们仅将这些信息用于：
- 提供用户请求的 WSL 管理与模板自动化功能。
- 存储用户偏好并改进本地使用体验。
- 展示执行进度、状态与诊断信息。

## 本地处理与设备访问
- 当用户发起相关操作时，DistroNexus 会调用本地 Windows 与 WSL 工具（包括 `wsl.exe`）。
- 这些操作在本机执行，核心流程不依赖账户登录。

## 网络访问
- DistroNexus 可能访问网络端点以下载已配置来源的目录/模板内容。
- 网络访问取决于用户配置与功能使用方式。
- DistroNexus 不提供应用内购买。

## 数据共享
- DistroNexus 不会主动出售个人数据。
- 除用户配置的端点或用户主动触发的操作外，DistroNexus 不会主动向第三方传输用户个人内容。

## 数据保留与删除
- 本地设置、缓存和日志会保留在设备上，直到用户修改或删除。
- 用户可通过删除应用数据文件或卸载应用来移除本地数据。

## 儿童相关
DistroNexus 是开发者工具，并非面向儿童设计。

## 安全性
我们在应用设计中采取合理措施以减少不必要的数据暴露。但任何软件系统都无法保证绝对安全。

## 政策更新
本政策可能会不定期更新。若发生重要变更，将通过更新生效日期反映。
