# 用户指南

DistroNexus 提供基于 WPF 的原生桌面工作流，并由 PowerShell 模块命令面提供能力支撑。

## 核心工作流

### 安装与初始化

可通过可视化流程安装新的 WSL 实例并完成基础初始化。

典型步骤：
1.  选择发行版系列与版本。
2.  选择安装路径。
3.  按需配置初始凭据。
4.  执行安装并查看进度反馈。

### 实例生命周期管理

可对已注册实例执行以下操作：

*   启动
*   停止
*   打开终端
*   移动
*   重命名
*   移除
*   设置或重置默认凭据

### 包与目录管理

可维护离线安装包与发行版目录元数据：

*   查询包信息
*   下载/缓存包
*   清理缓存包
*   更新目录数据

### 模板化自动化

内置模板可用于快速构建开发环境并实现可重复交付。

*   查询模板列表
*   应用指定模板
*   通过自动化命令执行标准化初始化流程

## 常见示例：将实例迁移到其他磁盘

1.  选择目标实例。
2.  执行 **Move** 并设置新路径。
3.  确认操作并等待完成。
4.  校验实例状态与路径更新结果。
