# v2.3.0 升级指南

v2.3.0 保留 v2.2.1 的发行版、设置、标签、备份、局部模板和实例注册信息。新增能力数据使用版本化 JSON 文件并采用原子写入。

首次 v2.3 写入可能把旧 JSON 包装进版本化信封。标签仍保存在设置负载中，未知设置会被保留。遇到更高版本的 schema 时，兼容路径只读处理；不要使用旧版本应用覆盖该文件。

升级前请按常规 Windows 备份方式复制 DistroNexus 应用数据目录。运行时不要编辑恢复日志、市场工件或工作区记录。升级中断时请保留原文件并使用诊断报告，不要删除状态文件。

升级不会自动启动 WSL、变更发行版配置、启用 Windows 功能、安装可选依赖或修改 USB 设备。Windows/WSL 支持矩阵、可选依赖、签名包、Store 行为和回滚演练仍需外部验收。
