# v2.3.0 安全与故障排查

远程模板目录、模板工件、工作区导入、Linux 应用元数据和容器输出都属于不可信输入。DistroNexus 会在授权操作前验证清单、哈希和声明路径。模板评审必须显式进行，并绑定当前选中的清单；工件变更后必须重新评审。

应用不会暴露任意提权命令。USB 操作使用受限协议；配置、恢复、服务、工作区和市场变更都先生成预览并要求确认令牌。PowerShell 的 `-WhatIf` 不会发出变更请求。

使用 `Get-Command -Module DistroNexus` 查看已安装模块的完整命令。功能不可用时，用 `Get-DistroNexusCapability` 查看稳定原因码。

自动化桥接与桌面端一样组合真实的 Core Health Center 检查：初始探测、能力、Windows 前置条件、全局与发行版配置、存储、备份、集成、网络、systemd、模板运行时预检、监控和 WSLg。桥接使用只读 PowerShell 适配器及受限的只读进程探测，因此健康扫描不会执行修复、备份、模板或监控变更；任何状态变更必须先获取预览，并显式确认后执行。

诊断输出在展示或导出前会脱敏。共享前仍应移除密钥、个人路径、令牌和私钥。不要在模板、工作区定义、命令参数或问题报告中加入凭据、签名材料或私人路径。
